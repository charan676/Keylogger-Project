# Keyboard Activity Monitor

A Python-based educational cybersecurity project that monitors and records keyboard activity using a graphical user interface built with Tkinter.

## Features

- Real-time keyboard monitoring
- GUI-based controls
- Text log generation
- JSON log generation
- Start and Stop monitoring
- Clear logs functionality
- Dark-themed interface

---

## Technologies Used

- Python
- Tkinter
- pynput
- JSON

---

## Installation

Clone the repository:

```bash
git clone https://github.com/charan676/Keylogger-Project.git
```

Move into the project folder:

```bash
cd Keylogger-Project
```

Install required libraries:

```bash
pip install -r requirements.txt
```

---

## Usage

Run the program:

```bash
python keylogger.py
```
